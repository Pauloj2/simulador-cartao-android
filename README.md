# 📱 Credit Card Simulator – Android Kotlin

---

## 📌 About the Project

This project consists of developing an Android application that simulates a credit card interface with dynamic real-time updates.

The project was developed following two main stages:

1. Visual prototype creation in **Canva**
2. System implementation in **Android Studio** using **Kotlin**

The goal was to apply concepts of:

- UI/UX
- ConstraintLayout
- Animations
- Event handling
- Card brand identification logic

---

## 🎨 Canva Prototype

Before implementation in Android Studio, a visual prototype was created in Canva to define:

- Screen structure
- Element layout
- Color palette
- User experience

## 🚀 Developed System

After the prototype, the application was implemented with:

- Kotlin
- ConstraintLayout
- Material Design Components
- Vector Drawables
- Shape Drawables
- Rotation animation (flip)

---

## 📱 Implemented Features

- ✔️ Card with front and back sides
- ✔️ Flip animation when clicking the CVV field
- ✔️ Real-time update of typed data
- ✔️ Automatic mask for card number
- ✔️ Automatic mask for expiry date (MM/YY)
- ✔️ Dynamic card brand detection (Visa, Mastercard, Other)
- ✔️ Automatic color change based on card brand
